# Interactive Tools

Single-file HTML/JavaScript tools built while learning. No build step — open in a
browser.

| File | What it does |
|---|---|
| `trading-sim.html` | Toy trading simulator: random-walk price generation, moving-average crossover signals, position and P&L tracking. The prototype the Python engine replaced |
| `study-partner.html` | Spaced-repetition drill tool for quant interview questions |
| `tracker.html` | Progress tracker for the study sequence |
